# 踩过的坑

这个文件夹记真实撞到过的 bug：现象是什么、怎么查出来的、原因、怎么修的、学到了什么。

一个 bug 一个文件，文件名是"日期 + 几个英文词"。每个文件都按下面这几块写：

1. **现象**：用户看到了什么。
2. **怎么查的**：按顺序写，走错的路也写上。
3. **原因**：一句话说清，再展开。
4. **怎么修的**：改了哪个文件、为什么这样改；有别的修法也写上为什么没选。
5. **怎么确认修好了**：用什么证明的；还没证明的也写明。
6. **学到的**：以后写代码要记住的规则。

注意：这里不写真实的人名、会话编号、密钥。例子里的访客一律叫"张三"。
