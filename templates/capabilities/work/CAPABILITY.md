# 分工

用户说"帮我查一下这三家公司的实习岗位要求"，Agent 可以派一个子智能体去查，自己等它回来。

子智能体就是把同一个循环再跑一遍，只是：对话是全新的，提示词换成 `templates/workers/general.md`，
工具只有"查"的那几个。它中间搜回来的东西留在它自己那段对话里，回到 Agent 手里的只有最后的汇报。

现在是"同步"的：派出去以后 Agent 等它做完，这期间不能接别的话。改成后台运行是下一步的事。

## 风险规则

- 子智能体只能查，不能改：能看时间、读文件、搜索、读网页，而且派它的 Agent 有哪些它才有哪些
  （`agents/tools/dispatch/dispatch.py` 的 `WORKER_TOOLS`，是允许名单）。写文件、发通知、定提醒、新建 Agent、
  再派别人，它都做不了。
- 子智能体的汇报可能带着网页里的话。所以只要派过单，这段对话就算"读过外面的内容"，
  之后改文件、发通知这些事要先问用户（`agents/permission/taint.py`）。
- 访客说话的时候也能用，规则和用户一样。
- 费钱：子智能体要带着自己的提示词从头开始。它每次调模型都记在用量里（名字是"编号·子智能体"），
  也受每天用量上限管。
- 知道的不足：子智能体做到一半停不下来（`/stop` 管不到它）；步数用完时它查到的东西带不回来。
